# @metreeca/clay-dnd

[![npm](https://img.shields.io/npm/v/@metreeca/clay-dnd)](https://www.npmjs.com/package/@metreeca/clay-dnd)

Preact drag and drop widgets for [@metreeca/clay](https://github.com/metreeca/clay).

Boards and lists whose items a reader rearranges by dragging them with the pointer, by touch or with the keyboard,
each move settled by the app before it takes effect, so the order on screen always matches the order the app keeps.

Styling is structural only: what a widget needs to work, with colour, type and spacing left to
[@metreeca/skin](https://github.com/metreeca/skin) or to whoever styles the app.

# Installation

```shell
npm install @metreeca/clay-dnd  # this package
npm install preact              # peer dependency
```

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.
